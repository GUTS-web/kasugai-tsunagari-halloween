# 出展者募集LP Brief

## 1. Project

- 案件名: 春日井つながり祭り2026 出展者募集
- LPの種類: 地域イベントのB2B / 団体募集
- 目的: 出展対象・料金・締切・申込経路を分かりやすく伝え、応募へ導く
- 主CTA: 出展ジャンルを選んで申込方法へ移動
- 副CTA: Instagram DM / 問い合わせメール
- 納品物: HTML / CSS / JavaScript / 生成画像 / QR画像 / スクリーンショット

- 地元の飲食店・キッチンカー

- 春日井が好きな個人・団体・事業者
